# 历史运行器源码参考

这里只保留旧正式测试、森林补评和中心 BFS 单树补评的三个运行器源码，供重建正式实验编排时参考。它们来自服务器副本，未携带旧数据、模型或结果。

这些文件绑定旧目录布局、冻结协议和 GPU/环境身份，**不能在此目录直接运行**，也不是新实验的命令入口。新运行器应使用新数据身份、路径与 4090 验收记录。

可独立使用的选边函数已经提取到 `Graph-Learning-BP/tools/baseline_topologies.py`；旧正式实验使用的加速后端已保留在 `tools/bp_cached_fast.py` 和 `tools/bp_distance.py`。生产训练与评价入口仍为 `python -m gib4cl`。
