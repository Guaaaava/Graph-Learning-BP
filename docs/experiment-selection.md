# 正式实验的预算、验证与参数选择

本页给出待执行的实验选择方案。候选网格和量级诊断不代表已完成验证的正式参数。目标公式沿用论文；正式测试集只用于冻结配置后的最终评价。

## BP 预算

固定先验支持是当前 BP 的积分方案。支持点、先验积分质量和消息具有共同语义，不应仅插入重采样而继续沿用旧消息。先验证现有方案是否足够，再决定是否需要带正确重要性权重的新提议分布。

在固定验证子集上，先检查 Dense、BFS 及若干预先固定的稀疏掩码，再用候选 GNN 掩码复核。可从粒子数 P=256、512、1024、2048 开始，资源允许时检查 4096；固定 P 后检查 T=3、5、10、20、40。网格是起点，不能代替稳定性证据。每组使用至少三个固定 BP 种子，并对不同拓扑共享支持。

比较不同 P 时，应先抽取最大 P 的支持，再按每个节点截取前缀并重设均匀先验质量；对不同形状直接重置同一个随机种子，不能保证每个节点都得到相同支持前缀。比较不同 T 时使用同一支持。

记录位置误差、协方差变化、覆盖率、无效协方差数、ESS、消息残差、时间和内存。预先规定可接受的结果变化，再选取最小且稳定的预算。高粒子数结果也是数值参照，不是真实后验。环图可能不收敛；未收敛结果应保留并标记，不能默认为收敛，也不能只删除失败运行。三种拓扑使用相同预算规则，并报告实际轮数与运行时间。

## 两种验证目标

训练目标的验证：令模型处于 eval 模式，通过 score_edges 得到 logits，再显式调用随机采样器，在 no_grad 下计算 K 次硬掩码的损失。先对每图的 K 次取平均，再对图等权平均。K=8 或 16 可作起点，并检查增加 K 后检查点排序是否稳定。

验证随机数按验证种子、sample_id、重复编号固定；跨 epoch 复用对应的均匀噪声，降低检查点比较的采样波动。不要仅依靠 model.train() 打开选边随机性，以免未来的 Dropout 等层也进入训练状态。

部署规则的验证：固定 p>0.5 或预先选定的阈值，记录实际拓扑、定位误差、通信成本和校准指标。BP 可对少量候选检查点运行，以控制成本。随机期望目标和确定性部署结果分别命名，预先指定主检查点选择规则，不能把后者称为前者的无偏估计。测试后不能再调阈值。

## 优化器设置

建议首先以 weight_decay=0 建立基线，保持优化器及其余设置不变；只有验证结果显示需要额外正则化时，再比较非零权重衰减。AdamW 的衰减独立于自适应梯度更新，会改变学习过程，不是目标公式的等价变形。

梯度裁剪可作稳定性保护。当前 max_grad_norm=5 是候选阈值，应记录裁剪前范数、裁剪比例和非有限梯度。频繁裁剪提示需要检查损失系数、学习率、温度和矩阵条件，而不是持续降低裁剪阈值。梯度范数上限不等于 AdamW 参数更新步长的上限。

LayerNorm 属于 MLP 内部的结构设置，可保留并在实验设置中说明。它是否有益应通过固定其余条件的消融实验判断。

## 协方差评价

论文讨论协方差可信度，因此主结果需要同时报告位置误差和不确定性：RMSE/MAE、NEES、多个名义水平下的椭圆覆盖率、椭圆面积、无效协方差率，并保留粒子 ESS 和收敛诊断。

椭圆与 NEES 是基于均值、协方差的评价。粒子后验不必为高斯，它们不能解释成真实粒子分布的精确置信区域。高斯 NLL 可作为辅助评分，与覆盖率、面积一起阅读；不应单独以提高覆盖率选择更宽的协方差。若要验证论文中逐方向的真实后验协方差关系，使用现有小图独立积分/穷举参照。需要实际后验的可信区域时，应另行定义和检验加权粒子的区域估计，而不是直接把矩匹配椭圆改名。

## 四个损失系数

当前目标为

```text
L = T + beta*(-H + gamma*E + kappa*C3 + R) + eta*D
R = sum_e p_e*log(M_e)
```

beta 同时缩放负熵与测量保留成本；通信和三角形的有效权重分别为 beta*gamma 与 beta*kappa。eta 独立作用于度数。四个值需要联合复核，但不必一开始做四维穷举。

1. 固定五锚点均匀 LOS 场景的数据划分、架构、优化器和采样温度方案，先完成 Dense/BFS 的预算检查。数据质量、测量噪声、初值误差和图规模应由场景设计决定，不能为得到理想方法优势而按测试结果调整。
2. 在训练集小样本上记录各分项值及其对 GNN 参数的梯度范数。任务 NLL 可以为负，且含参数无关常数；不要仅按原始损失绝对值配平。
3. 令 gamma=kappa=0，先检查 beta 与 eta 控制的定位、删边和低度数行为。可用非零梯度范数的比例提供 beta、eta 的初始量级；梯度为零时不作除法，也不据此声称该项不重要。
4. 引入 gamma。以 log(M) / 典型单边通信成本作为起始量级，使单边通信项与保留数据项具有可比较的尺度；围绕该量级做对数搜索。
5. 引入 kappa。以固定参考概率下的保留数据成本与期望三角形数之比提供起点；没有三角形的图不提供 kappa 的识别信息。加入 gamma、kappa 后重新检查 beta、eta 邻域。
6. 初始系数可按参照值乘以 0.1、0.3、1、3、10 搜索，并包含适用的零值消融。它们是搜索起点，不是正式推荐值；完整方法的 beta 必须大于零。
7. 验证时比较实际 BP 表现、通信成本和协方差可信度，绘制 Pareto 前沿。候选系数之间的总损失采用不同权重，不能直接按最小总损失给超参数排序。先约定可接受的精度与校准退化，再从满足条件的候选中选通信成本低且跨种子稳定的配置。
8. 少量种子粗筛，多个独立训练种子复核，冻结参数及 BP 预算后只做最终测试。若要报告多个 beta 的权衡曲线，所有扫描点和各自选参预算须预先固定。

系数量级诊断不执行优化，也不观察验证性能；它只能缩小搜索范围。正式配置中的空值在验证选择完成后填写，不用 smoke 参数替代正式选择。

## 当前范围

当前只保留四角加中心五锚点、全区域均匀智能体、统一通信半径的生产场景。旧的多场景初始化诊断不作为当前参数的正式依据；应在当前训练集重新诊断并按验证集选择系数。这里只保留选择方法，正式损失系数和 BP 预算仍待相应验证。
