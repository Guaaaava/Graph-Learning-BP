# 第二章粒子 BP 树与单环对照实验计划（已确认）

日期：2026-10-29。用户已确认本计划并授权实现。[代码运行说明](tree-loop-experiment.md)已提供。本文保留实现前的设计依据，下文参数是设计起点；实际预算与实测结果以各次运行的配置、原始记录和汇总为准，“预期”不作为实测结果。

## 1. 建议采用的方案

用一个**三个未知节点的二维测距问题**作为主实验：左侧为链式树 `1—2—3`，右侧在相同节点上增加物理测量边 `(1,3)`，构成三角环。每张图都同时计算粒子 BP 和该图的独立精确边缘参照。通过这种四组对照，区分新增观测的作用与 BP 推理误差。

最终建议交付两张图：

1. **机制图**：两列分别是树和单环；上排比较同一节点的 BP 与精确参照协方差椭圆，下排展示方差比随消息轮数的变化。
2. **统计图**：展示多次独立观测试验的可信区间覆盖曲线，配合 NEES、定位 RMSE 和方差比统计。

若第二章只能容纳一张图，优先保留第一张综合图，将统计结果压缩成图下注释或一张小表。第一次实验无需从生产场景的 25–35 个智能体开始，也无需引入 GNN、复杂随机几何图或多种改进算法。

要支撑的表述是：

> 在所考察的测距几何与信息强度下，环上的粒子 BP 即使收敛，也可能相对同一观测模型的真实边缘后验低估某些方向的不确定性；这种偏差不能由新增测量带来的合法信息增益解释。

不把结果扩展为“所有环必然导致过度自信”“树的定位一定更准”或“环越少必然越好”。这与当前第二章的方向性方差定义及其适用范围一致。

## 2. 为什么只比较树和环的椭圆大小不够

给树增加一条独立测距边，会同时改变图结构、观测集合、精确后验和 BP 结果。因此，环图上的 BP 椭圆小于树图上的 BP 椭圆，本身不能说明过度自信。

每一组观测需要以下四个结果：

| 观测模型 | 独立后验参照 | 粒子 BP |
| --- | --- | --- |
| 树 T，使用 z12、z23 | p*(Y \| z12,z23) | bT(Y) 的节点边缘 |
| 单环 C，使用 z12、z23、z13 | p*(Y \| z12,z23,z13) | bC(Y) 的节点边缘 |

重点分别检查 `BP(T) 对 Exact(T)` 和 `BP(C) 对 Exact(C)`。后者才直接检验环图的推理偏差；`Exact(T) 对 Exact(C)` 则刻画新增观测对后验的影响。

对于某个固定方向，两个 BP 结果的方差差异，可以分解成“两个精确后验的方差差异”加上“两个推理误差的差异”。因此，不必人为让新增边没有信息，也不必强行让两张图的精确协方差相等。

还需避免两种误解：新增观测在平均意义下可以降低贝叶斯估计风险，但在非线性问题中，对某次具体观测，不保证每个方向的条件后验方差都变小；同一物理边的两个消息方向也不是两次独立观测。

## 3. 图、几何与观测模型

### 3.1 主实验

| 项目 | 建议设置 | 原因 |
| --- | --- | --- |
| 未知节点 | 3 个，每个位置为二维变量 | 最小的简单环；联合未知量仅 6 维，能够建立独立参照 |
| 树 | E(T)={(1,2),(2,3)} | 结构透明，同步传播足够后应与同一有限模型的精确后验一致 |
| 单环 | E(C)=E(T)∪{(1,3)} | 只增加一条真实测量边，形成一个三角环 |
| 先验中心 | c1=(0,0)、c2=(10,1)、c3=(20,0)，单位 m | 细长、非共线布局，便于观察沿走廊方向的相关不确定性 |
| 先验 | 各节点独立 N(ci, I m²) | 有限且已知的绝对位置先验，保证后验适定 |
| 测距 | zij=\|xi−xj\|+εij | 保留论文与当前 BP 的非线性欧氏测距因子 |
| 主噪声 | εij 独立，N(0,0.5² m²) | 相对测量比绝对先验更强，但不直接采用近乎无噪声的约束 |
| 距离相关系数 | α=0 | 这是论文模型允许的特例；避免闭环边较长同时改变测量方差 |
| 锚点 | 主实验不额外添加 | 绝对信息由明确的高斯先验提供，避免混入不同锚点布局的影响 |
| 图的生成 | 预先规定这三条候选边 | 不按某次真值、测量误差或算法表现重新选边 |

这里不宣称细长布局代表所有二维网络。它是一个有物理解释的机制场景：相对测量较强、绝对先验较弱，节点之间容易形成相关误差。该几何的选择理由来自近似一维的相关结构，实际偏差方向仍由非线性后验参照检验。

主实验包含完整二维位置变量，不把测距替换为线性化量，也不使用 FIM/CRLB 充当真实后验协方差。若希望图示中保留已知锚点，可在补充试验里加入固定锚点测量，并保证两张图保留完全相同的局部因子。

### 3.2 建议的复核与可选扩展

| 层级 | 对照 | 回答的问题 |
| --- | --- | --- |
| 必做复核 | 保持端点 c1、c3，令 c2=(10,10√3)，形成等边布局；先验和噪声不变 | 现象是否依赖几何；是否存在某方向低估、另一方向高估 |
| 建议补充 | 主几何下 σr=1、2 m，主条件仍为 0.5 m | 环效应是否随相对测量与先验的强弱变化 |
| 建议补充 | 将三角图的另外两棵生成树也作为树参照 | 避免结论只对应某一条被删除的边 |
| 可选扩展 | 6–8 个节点的树加一条弦，或长度 4、6 的单环 | 检查现象是否局限于三节点模型 |

等边复核即使不表现出相同的低估，也应报告。它能约束结论的范围，不能因为不符合预期而更换布局。长度不同的物理环还会改变几何和有效耦合，不能仅凭这些扩展宣称“环越短一定越过度自信”。

如果以后要直接支撑三角形惩罚项的优越性，需要另外设计受控的环长度/耦合消融。本次最小实验只支撑第二章的机制说明。

## 4. 精确参照：先隔离消息误差，再检查连续近似

当前项目已有固定支持粒子 BP，以及独立的有限支持联合后验穷举程序。这一条件非常适合本实验，但必须区分两层“精确”。

### 4.1 相同支持上的精确后验：主证据

给定每节点 P 个支持点及正确的先验积分质量，在三节点联合空间中直接计算所有 P³ 个组合的后验权重，再求各节点边缘、均值和协方差。树和环都使用与各自 BP 完全相同的点、先验质量和观测因子。

这样，在一个确定的有限概率模型中，粒子 BP 与精确结果之间的差异来自消息推理，而不是两种方法用了不同的积分点。对于固定支持、标准 cavity 消息的树 BP，充分传播后应吻合该有限模型的精确边缘。

P=128、256、512 时，联合状态数量分别约为 210 万、1678 万、1.34 亿。当前穷举参照默认上限为 200 万，因此正式实现时需要显式设定受控预算，或针对三节点模型采用独立的精确矩阵缩并；不能未经评估就扩大到大图或 P=10000。

这种参照精确的是**有限支持模型**，不能直接命名为连续测距后验的解析真值。

### 4.2 连续后验复核：排除粒子支持造成的假象

在预先固定的一小组观测上，以独立的二维节点求积组成六维后验积分，检查求积加密后的均值和协方差稳定性；必要时用另一种独立积分方法交叉核验。可从每轴 9、13、17 阶求积开始，精度不足时继续加密，不能把这些阶数本身当作精度保证。

同时检查随机先验支持 P=128、256、512，必要时 1024 下的 BP 与精确有限模型结果。不同 P 尽量复用每个节点的支持前缀；不能假设对不同张量形状设置同一种子就自然得到相同前缀。

建议接受标准：连续数值参照最后两级协方差的相对变化低于 1%，且明显小于拟报告的过度自信效应；P 翻倍后，主要方差比的总体变化不超过 0.02。阈值可在正式观测试验前根据预实验资源冻结，但不能事后为得到理想结论修改。

若这些条件未满足，应先提高积分/粒子预算或缩小结论范围，不能把支持遗漏、权重退化直接解释成环效应。较大的粒子数结果或 MCMC 样本本身也不自动等于精确参照。

## 5. 主要指标及其解释

### 5.1 主要证据：相对同图后验的方向方差比

对单位方向 u，定义

\[
r_i(u)=\frac{u^T\Sigma_i^{BP}u}{u^T\Sigma_i^*u}.
\]

`r=1` 表示该方向一致，`r<1` 表示低估，`r>1` 表示高估。主几何预先指定走廊方向 u=(1,0)，直接对应第二章的方向性过度自信定义。

另外报告

\[
A_i=(\Sigma_i^*)^{-1/2}\Sigma_i^{BP}(\Sigma_i^*)^{-1/2}
\]

的两个特征值 λmin、λmax。其含义是全部方向上广义方差比的最小值和最大值：λmin<1 说明存在低估方向，λmax<1 才说明所有方向都低估。若两者跨越 1，报告方向性差异，不称为整体协方差严格偏小。

协方差迹比和椭圆面积比可以辅助汇总，但它们可能掩盖不同方向的相反偏差，不能替代以上指标。每个节点均纳入统计，不能只报告最显著的节点。

### 5.2 NEES：评价误差与所报不确定性的匹配

\[
q_i=(\hat x_i-x_i)^T(\Sigma_i^{BP})^{-1}(\hat x_i-x_i).
\]

报告平均 NEES 与归一化平均 NEES/2。对于二维问题，在真值按推理模型生成、均值与协方差为精确条件矩时，NEES 的期望为 2；这一期望不要求后验必须高斯。

但是，NEES 偏大既可能来自协方差偏小，也可能来自均值偏差，因此必须与方向方差比和均值误差一起解释。只有高斯假设下，才可进一步将单次 NEES 按 χ²₂ 分布解释；不把所有节点、所有粒子种子当作相互独立样本构造卡方区间。

### 5.3 覆盖率：验证“说 95%，实际覆盖多少”

主要统计曲线建议采用**预先固定方向上粒子边缘的等尾可信区间**：由加权粒子计算 50%、80%、90%、95%、99% 区间，再统计真值落入区间的比例。参照后验使用同样定义。这样无需把非高斯粒子后验强行当成高斯。

现有评估层中的高斯等效椭圆覆盖率仍可报告，95% 阈值为 χ²₂(0.95)≈5.991。必须明确：该椭圆由均值和协方差匹配而来，不是任意粒子后验真正含 95% 质量的区域。若采用它作为主图，需要同时绘制精确后验的矩匹配椭圆覆盖曲线，避免把非高斯形状本身造成的偏差归因于 BP。

本计划不要求首先实现二维 KDE/最高密度区域；它会引入带宽和区域估计误差。

### 5.4 其他指标的角色

| 指标 | 作用 | 优先级 |
| --- | --- | --- |
| 位置 RMSE | 判断均值估计有没有改善或恶化 | 必报，但不能单独判断过度自信 |
| 相对精确均值的误差 | 区分均值推理偏差与协方差偏差 | 必报 |
| 消息残差、收敛标志、实际轮数 | 说明是否达到固定点 | 必报诊断，不能充当准确性证明 |
| ESS、最小协方差特征值、无效协方差率 | 检查支持退化与数值问题 | 必报诊断 |
| 相同支持边缘 KL(p* \| bBP) | 检查包括尾部在内的分布误差，可直接用离散权重计算 | 建议补充 |
| 高斯 NLL、椭圆面积 | 辅助描述不确定性质量和尺度 | 可选 |
| 时间、内存、通信量 | 确认实验预算 | 记录即可，不作为第二章主图 |

协方差无效时保留失败标志，不用额外 jitter 将其改造成看似有效的校准结果。

## 6. 重复试验、共享随机数与统计单位

每次独立数据试验先按 xi~N(ci,I) 生成真值，再按三条候选边各自的独立噪声生成观测。树读取其中两条，环读取全部三条。这样重复试验与推理的先验、似然一致，便于解释 NEES 和覆盖率。

不采用“固定某个真值，只不断改变粒子种子”来估计 95% 覆盖率。那主要衡量算法积分随机性，不能替代独立观测试验。也不把当前大场景生成器中“均匀真值加初值误差”的协议直接当作本实验的先验预测校准协议。

建议预算：

| 项目 | 起始预算 |
| --- | --- |
| 数值预实验 | 20 组独立观测，3 个粒子种子，比较 P=128/256/512 |
| 主几何正式试验 | 200 组独立观测，每组 3 个粒子种子 |
| 等边几何复核 | 100 组独立观测，每组 3 个粒子种子 |
| 额外噪声条件 | 每个条件 100 组，视确认后的范围执行 |
| 主粒子数候选 | P=256，经数值预实验后冻结；不沿用生产配置的 10000 作为默认 |
| 消息轮数 | 保存 t=0…50 的历史；无阻尼作为主设置 |

同一试验内，树、环和其他树掩码共享先验、公共边测量和粒子支持。粒子种子描述积分误差；数据种子描述独立真值与观测变化；两者分开保存。BP 随机种子由独立试验编号和粒子重复编号共同派生，使不同数据试验之间的粒子随机性也独立，同一配对内仍共享支持。

先在每组数据内汇总节点及粒子重复，再按独立数据试验进行成对 bootstrap，建议 2000 次，报告 95% 区间。不能把 200×3×3 个输出直接当成 1800 个独立数据样本。参数/几何条件间也尽可能共享底层标准正态随机数，降低对照方差。

200 次是起始预算，足以观察较明显的覆盖率差异，但不能保证识别 2–3 个百分点的小差异。若预实验显示需要更精细的覆盖率比较，应依据预实验方差在正式试验前确定更大的样本数。

收敛沿用当前归一化 log 消息残差容限 1e-8，并记录逐轮 belief 变化。树上 belief 在充分传播后应稳定；三节点链通常两轮已包含全部图信息，残差判据可能再需要一次更新。环图未收敛的运行必须保留并单独标记，不能只删除失败结果。若需使用 0.5 阻尼，作为独立的数值稳健性条件报告。

## 7. 具体出图设计

### 图 1：左右对照的机制综合图，优先制作

| 位置 | 左：树 | 右：三角环 |
| --- | --- | --- |
| 上排 | 节点 2 的精确参照与 BP 协方差椭圆 | 同一节点、同一数据试验的精确参照与 BP 椭圆 |
| 上排角落 | 三节点链的小拓扑插图 | 三节点三角形，新边用强调色 |
| 下排 | λmin、λmax 或指定方向方差比随 t 的曲线 | 完全相同的指标与坐标范围 |

绘图细节：

- 精确参照用深灰轮廓，树 BP 用蓝色，环 BP 用橙红色，真值用黑色星号；均值各自标记，椭圆各自以其均值为中心。
- 上排使用相同坐标比例、窗口大小和椭圆概率系数；图注称为“矩匹配协方差椭圆”，不能凭椭圆单次是否覆盖真值下结论。
- 下排加水平线 1，并用很淡的阴影标出方差低估区域。多次数据试验的总体曲线可报告中位数与明确标注的分位带，或均值与 bootstrap 区间，不能混淆两种带的含义。
- 说明椭圆展示的是预先固定编号的数据试验；总体判断依赖全部试验。不要专挑最窄或误差最大的一次作为唯一证据。
- 主参照若采用同一有限支持的精确后验，图注明确写出，连续求积复核放在补充表。若后续改用连续参照，必须对两列统一更换并重新核对指标口径。

这张图同时回答“树是否正确”“环图是否相对自己的参照变窄”“收敛后偏差是否仍存在”。动态曲线不预设方差必然随轮数单调下降，也不将某个反馈轮数前的结果视为自动精确。

### 图 2：统计校准图，建议制作

左面板画名义可信水平与实际覆盖率的关系，含树 BP、环 BP 和相应精确参照；对角线代表名义水平与覆盖率相符。采用上述投影等尾区间时，对角线的含义最直接。覆盖率的参照基准优先采用已验证的连续数值后验；若因预算使用有限支持参照，应明确其离散近似并复核加密后的覆盖曲线，不能要求它在连续生成真值的试验中严格贴合对角线。

右面板画全部独立试验的成对方差比或归一化 NEES，可用半小提琴加散点的 raincloud 风格，并叠加均值/中位数和区间。每个点的统计单位应是一次独立数据试验，不能以多个粒子种子扩充独立点数。小表同时列出 RMSE、NEES/2、95% 覆盖率和无效率。

如果需要更突出二维方向性，可将右面板替换为“角度—方向方差比”极坐标曲线，以半径 1 的圆为参照。它比单一 trace 比更能展示某些方向过度自信、另一些方向并非如此；但正文图不同时堆叠所有备选样式。

以下是已核对的原始论文。其方法与粒子实现细节不必照搬；借鉴的是小图参照、分布对照和校准展示的思路。

1. **Savic, Wymeersch, Penna, Zazo, ICASSP 2011，Optimized edge appearance probability for cooperative localization based on tree-reweighted nonparametric belief propagation。** 小规模部分采用四个目标节点的全连接图、每个目标一个锚点，进行一维定位，能够计算真实边缘；论文设置包含 200 粒子、8 轮和 200 次 Monte Carlo。Figure 3 直接叠画真实 belief、NBP 与 TRW-NBP belief；Figure 2 同时考察 KL 与 RMSE。可借鉴“小图真实参照”和“一张图直接展示分布过窄”，不要把其粒子预算直接当成本项目二维实验的已验证设置。[论文 PDF](https://www.diva-portal.org/smash/get/diva2:552321/FULLTEXT02.pdf)

2. **Savic & Zazo, 2013，Nonparametric generalized belief propagation based on pseudo-junction tree for cooperative localization in wireless networks。** Figure 6 比较不同方法的二维初始和最终 belief，并标出真值；文中专门讨论两种方法使用相同 thin graph 的对照意义。适合借鉴二维后验展示。它不是本计划所要求的精确树/环四组参照，不能将其近似方法当作精确真值。[原文及 Figure 6](https://link.springer.com/article/10.1186/1687-6180-2013-16)；[Figure 6 图片](https://media.springernature.com/lw685/springer-static/image/art%3A10.1186%2F1687-6180-2013-16/MediaObjects/13634_2011_Article_430_Fig6_HTML.jpg)

3. **Weiss & Freeman, NeurIPS 1999，Correctness of Belief Propagation in Gaussian Graphical Models of Arbitrary Topology。** 分析说明高斯 loopy BP 收敛时均值可以正确，而方差仍有偏差，并用展开树解释重复信息；文中在正相关情形讨论方差低估。它支持将均值准确性、消息收敛和协方差准确性分开评价。其高斯结论不能未经验证直接推广为非线性测距模型的定理。[论文 PDF](https://proceedings.neurips.cc/paper_files/paper/1999/file/10c272d06794d3e5785d5e7c5356e9ff-Paper.pdf)

4. **Kuleshov, Fenner, Ermon, ICML 2018，Accurate Uncertainties for Deep Learning Using Calibrated Regression。** 可借鉴预测概率与经验覆盖关系的 calibration plot，以及将区间宽度与覆盖频率一起阅读的表达方式。这里只借鉴展示，不在本实验中对 BP 做事后校准。[论文与 PDF](https://proceedings.mlr.press/v80/kuleshov18a.html)

本计划的近一维主几何、两层参照、方向特征值和具体预算，是针对当前项目提出的设计，不是以上任一论文已报告的实验结果。

## 9. 可选的解析机制校验：帮助解释主几何

若需要一个完全可解析的辅助例子，可考虑三个标量变量 xi，各有独立先验方差 σp²，边观测为 `zij=xi−xj+εij`，噪声方差 σr²。设 a=1/σp²、b=1/σr²。在三角图中，精确后验精度为 J=aI+bL，L 是三角图的拉普拉斯矩阵。

每个节点的精确方差为

\[
v^*=\frac{a+b}{a(a+3b)},
\]

标准高斯 BP 对称固定点报告的方差为

\[
v^{BP}=\frac{1}{\sqrt{a^2+4ab}}.
\]

例如 σp=1、σr=0.5 时，两者分别为 5/13≈0.3846 与 1/√17≈0.2425，方差比约 0.631。这是上述简化模型的代数结果，不是已经运行的粒子 BP 实验。它解释了为什么“较强的相对观测、较弱的绝对先验”值得作为机制场景，但不能替代二维非线性测距实验。

不建议为了这个辅助例子先改写生产 BP 支持另一套观测模型；可以只作为推导或补充校验，待确认是否需要。

## 10. 实验完成后如何判读

| 观察 | 合理结论或下一步 |
| --- | --- |
| 树与相同支持精确边缘仍不一致 | 先检查传播轮数、cavity 排除、先验积分质量与实现；暂停解释环效应 |
| 树吻合，环在同一模型参照下某些方向方差比稳定小于 1 | 得到该场景中环导致方向性过度自信的直接证据 |
| 环相对树更窄，但与环自己的精确后验吻合 | 主要是观测改变，不能据此宣称推理过度自信 |
| 方差比随 P 增加趋近 1，或树也表现出明显连续后验偏差 | 粒子/积分误差可能主导，需要提高预算或调整参照 |
| 环 NEES 偏大，但协方差没有低估 | 先查均值偏差，不能把 NEES 的全部异常归因于方差 |
| λmin<1、λmax>1 | 结论限于方向性低估，不能称所有方向均过度自信 |
| 环消息不收敛 | 报告非收敛及有限轮结果，不把它冒充收敛固定点的过度自信 |
| 不同几何得到不同偏差方向 | 如实展示；结论强调条件，不换种子追求统一方向 |

若结果支持预期，正文可围绕三条事实组织：树与其参照一致；环与其自身参照出现方差低估；该偏差在积分加密与独立观测试验中持续存在。NEES、覆盖率和收敛状态为这个判断提供补充证据。

## 11. 与现有工程的关系及确认后的执行顺序

可以复用：固定先验支持、二值边掩码、共享支持、逐轮历史、正确 cavity 消息、双精度 log 域计算、已有矩/NEES/椭圆指标及独立小图穷举参照。

独立实验层已实现：固定三节点几何和先验预测数据、小图精确参照缩并、方向方差比、粒子投影区间覆盖、成对试验汇总和综合出图。接口、验证和结果文件说明见[运行说明](tree-loop-experiment.md)。

实施顺序：

1. 冻结主几何、观测模型、两图因子集合和图形布局。
2. 做小规模数值预实验，核对树的精确性，并确定 P、积分阶数和轮数预算。
3. 固定数值预算和种子，运行主实验与等边复核；根据确认范围追加噪声复核和其他生成树。
4. 生成两张图、指标汇总和可复核原始记录，再据实际结果撰写第二章实验段落。

建议本次确认的最小范围：**三节点二维树/三角环＋各自精确参照＋200 次主场景独立试验＋等边几何复核＋两张图**。更大网络、长环和 TRW 等改进算法留到主机制确认之后。
