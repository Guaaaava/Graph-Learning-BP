# 第二章论文选图建议

推荐以用户方案二为主线：七节点树／分支闭环的 mechanism、calibration 均针对中央节点 i，解释过度自信；环长对照在同一坐标轴比较节点 i 和全网络平均，提供优先关注三角环的实验动机。三节点图作为简洁机制复核保留于附录，正文不重复展示两套完整实验。

## 选择的依据

| 方案 | 优点 | 需要交代的限制 |
| --- | --- | --- |
| 三节点为主 | 最小闭环直观，沿走廊 x 方差比约 0.670，95% 覆盖率由树的 93.28% 降至环的 87.00%，视觉证据强 | 与 Fig.1 的分支反馈结构联系需要额外解释；若再接七节点环长图，读者要切换模型 |
| 七节点为主 | 与 Fig.1 的分支结构呼应；过度自信、分支反馈、不同环长度在同一基础网络下衔接 | 五环的方差低估较弱；覆盖率缺口也较小，不能作为唯一有力证据 |

选择标准是论证与论文结构的一致性，而不是把哪张图的偏差画得更大。七节点走廊的五环中央节点 x 方差比为 0.873 [0.867,0.879]，全部节点平均为 0.909 [0.905,0.913]，这已足以说明同图后验下的方向性方差低估。对应树 BP 与精确有限支持后验吻合。

## 正文组织

1. 以 Fig.1 说明分支之间连接后形成反馈路径；结合七节点 mechanism 的灰色精确后验与彩色 BP 椭圆，展示报告方差的偏差。机制图左列为树、右列为五环，上排固定试验，不能仅靠这一个样本下结论。拓扑示意将 i 放在顶端，五环新增边展示为对称的 b-c；这是对原始 a/b 的展示名称交换，原数据和边没有变化。
2. mechanism 下排的试验平均方向方差比承担定量证据；最小方向低于 1、最大方向可略高于 1，表述限定为方向性低估。若版面紧，可将迭代过程移至附录，正文保留左树右环的椭圆对照。
3. 七节点 calibration 与 mechanism 一样只评价中央节点 i；其余节点不参与主要校准统计。平均七个节点回答网络整体表现，原先采用它是汇总选择，并不是校准定义的要求。节点 i 的名义 95% 区间覆盖率为树 94.00%、五环 BP 91.00%、五环精确有限后验 92.67%；相应试验级 95% bootstrap 区间分别为 [89.67%,97.67%]、[85.67%,95.33%]、[88.00%,96.34%]。不再跨节点平均，统计波动可能更大；保留真实区间宽度，不能通过缩窄置信带来改善视觉效果。所有节点平均的旧口径仍在 calibration-all-agents 补充图中，原配对比较文件 paper-selection-statistics.json 也明确属于全节点平均，不能套用于节点 i。
4. 环长图把中央节点 i 和全节点平均 x 方差比叠加到同一坐标轴，用不同颜色、线型及点形区分；上方的三个拓扑示意标明相应闭环边。正文说“在考察的布局中，三环的该方向低估强于四环和五环，为优先关注三角环提供动机”。闭环边同时改变方向、端点和局部度数，因此不给出“短环一定更差”的普遍结论。

若正文空间有限，建议正文放一组七节点机制／校准图和一张环长合并图；三节点、全节点校准、完整协方差／消息收敛、展开布局与标量高斯控制放入附录。若不准备在第二章引入环长对照，也可只用七节点主图，并将三角环优先级作为后续算法设计及消融实验要检验的假设。

## 绘图约定

所有校准图恢复阴影置信带。标准术语保留在坐标轴中，横纵轴均为 x-credible intervals。图内仅保留必要图例、坐标轴与子图编号；不加图表标题、箭头解释或长页脚。精确边缘后验图例写作 Exact posterior，校准图简写 Exact (loop)，其有限支持与同图条件写入图注。阴影明确为平均经验覆盖率的逐点 95% bootstrap 置信区间，不是位置的 95% 后验可信区间，也不是各次结果的最大最小范围。
