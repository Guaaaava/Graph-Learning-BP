## 环长结论的边界与辅助控制

保持节点、边和独立环数量相同，并不能使二维物理模型只剩环长度一个变化：闭环边的方向、端点及局部度数也会改变。因此这组对照检验同一基础网络上不同闭环方式的实际影响，不预设偏差一定随环长单调。

为区分这些因素，另给出计算量很小的标量高斯辅助模型：

\[
p(x)\propto\exp[-\tfrac a2\sum_i x_i^2-\tfrac b2\sum_{(i,j)}(x_i-x_j)^2].
\]

每个节点度数为 2；单条曲线固定一元精度 a=1 和每边耦合 b（分别取 1、4），只改变同质环长度 L=3…8。精确协方差由精度矩阵求逆，高斯 BP 方差由精度消息固定点求得；两种计算独立。

这个正耦合高斯控制中，较短环有更大的方差低估，属于该模型条件下的结果，不是二维测距图的普遍定理。图及原始数值为 `gaussian-ring-control.*`、`gaussian-ring-control.json/csv`，随七节点图形输出生成。辅助模型不替代粒子 BP 的物理拓展，也不据此保证三角环删边一定改善定位。
