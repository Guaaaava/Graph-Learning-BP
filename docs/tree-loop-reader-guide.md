# 如何理解精确有限支持参照、可信区间与一致性检验

## reference 为什么出现在标签中

reference 在这里指“比较基准”：用来核对 BP 输出偏差的基准答案。它不是额外的一种分布、测量或推断方法。基准答案的对象是后验，因此先前省略了 posterior 的 Exact finite reference 标签不够清楚。现将图例简化为 **Exact posterior**，在图注中交代“对同一有限粒子模型精确”。

对于同一图、同一观测、同一粒子点集和先验权重，可以得到两份节点后验权重：一份通过 BP 迭代求得，另一份通过精确边缘求和求得。后者就是比较基准。机制图的灰色椭圆由后者的均值和协方差绘制；它不是围绕真值额外假设的分布。

## finite 指什么

finite 指每个未知节点的位置只在有限个候选粒子状态上取值。每个粒子本身仍然是一组二维坐标。每节点 P=256 时，三个节点的离散联合空间有 P³=16,777,216 个位置组合，而不是连续平面上的无穷多个状态。

已知点集本身还不够。还需要先验积分质量 w0、观测 z 和似然因子 ψ。对三个节点，直接构建

\[
\pi(k_1,k_2,k_3)\propto
\prod_{i=1}^3w_{0,i}(k_i)
\prod_{(i,j)\in E}\psi_{ij}(x_i^{(k_i)},x_j^{(k_j)}),
\]

归一化以后，节点 1 的精确边缘为

\[
w_1^*(k_1)=\sum_{k_2,k_3}\pi(k_1,k_2,k_3).
\]

Exact reference on finite particle support 指这个边缘求和在给定有限模型中精确，并非声称有限粒子已经精确表示连续后验。生产 BP 与此参照共用支持、先验质量和观测，因此两者的差异可以隔离消息近似误差。另用独立连续求积加密检查离散误差。

对于七节点树／单环，先消去树枝、缩并单环、恢复分支边缘，仍然精确求有限后验；复杂度为 O(NP³)，无需枚举 P⁷ 个组合。该参照不调用生产 BP。

## 后验、概率质量、可信区间

后验是给定观测后对未知位置的分布。精确算法计算 p*(x|z)，BP 提供其近似 belief bBP(x|z)。两者均可各自给出可信区间。

对 BP 的 x 坐标边缘，一个名义 c 的可信区间 C_BP(c;z) 满足

\[
P_{b_{BP}}\{X\in C_{BP}(c;z)\}\approx c.
\]

“包含 95% 概率”指这个分布在该位置区间内分配了约 95% 的概率质量，而不是说一个固定真值有 95% 的宽度，也不是先用精确后验替 BP 选择区间。

在加权粒子表示中，该概率质量是落入区间的粒子权重之和，不是粒子个数的简单比例。等尾 95% 区间取 x 边缘的 2.5% 和 97.5% 分位数。有限粒子的原子质量会使闭区间实际包含的质量略高于名义值。

credible 是贝叶斯统计中“可信区间”的标准术语：给定观测以后，该后验为未知位置落入区间这一事件赋予指定概率。对于 BP，指 BP 的近似后验所赋予的概率。这个名称不保证近似后验正确校准，所以还要检查重复试验中真值的经验覆盖率。横、纵轴现在均写明 x-credible intervals，分别表示同一类 x 坐标区间的名义概率质量和经验命中频率。

例如 BP 给出 x∈[9.0,11.0] m 的名义 95% 区间。这表示 BP belief 在此范围内放置约 95% 质量。评估时模拟器知道真值，可以检查这一次是否落入区间。换一组真值和观测，区间也会改变；反复统计命中频率，得到经验覆盖率。名义 95% 与经验覆盖率 87% 不一致，意味着所报区间覆盖不足，但仍需结合方差比、均值误差确定原因。

## 三种“95%”不要混淆

| 学术术语 | 区间针对什么 | 本实验中的含义 |
| --- | --- | --- |
| 95% posterior credible interval，后验可信区间 | 给定观测后的未知位置 X | 某一方法的后验／belief 分配约 95% 质量的位置区间 |
| 95% bootstrap confidence interval，bootstrap 置信区间 | 平均覆盖率、平均方差比等统计量 | 依据独立数据试验重抽样，描述该均值估计的统计不确定性 |
| 95% chi-square acceptance region，卡方接受域 | NEES 统计量 q | 在高斯且正确均值／协方差的 H0 下，q 有 95% 概率落入的范围 |

这些都采用 95% 这个数，但对象不同。可信区间的宽度描述位置不确定性；均值置信区间的宽度主要描述当前试验数对统计均值的估计精度。

## NEES 的卡方检验能说明什么

Liang 与 Meyer 的 NEBP 论文 §4.2 在真实后验高斯的假设下采用双侧 χ² 检验评估一致性。[原文](https://arxiv.org/pdf/2105.12903)

对二维位置，H0 为输出均值和协方差与真实后验矩一致，且采用高斯参考模型；则 q=NEES 服从 χ²₂。名义水平 c=1−α 的双侧接受域为

\[
[F_{\chi^2_2}^{-1}(\alpha/2), F_{\chi^2_2}^{-1}(1-\alpha/2)].
\]

c=95% 时约为 [0.0506,7.3778]。理想情况下，低于下界和高于上界的比例各为 2.5%。

- 上尾比例过高：实际误差相对所报协方差过大，与过度自信相容，也可能来自均值偏差、模型失配等。
- 下尾比例过高：误差相对所报协方差过小，可能表现为保守，也可能来自其他分布形状差异。
- 仅知道“双侧检验拒绝率高”，只能判断与 H0 不一致，不能辨别是哪一侧异常。
- 未拒绝 H0 并不等于证明分布正确；该诊断也不是完整的分布拟合优度证明。
- 任意非高斯粒子后验不自动满足卡方分布。矩正确时 E[NEES]=2 仍可成立，但整个卡方分布的假设更强。

上述内容保留为历史方法解释。按当前展示选择，NEES 暂不用于图表和报告主表；已有原始数值保留以供追溯。主要证据采用同图精确后验下的方向方差比，以及直接由加权粒子构造区间的经验覆盖率。
