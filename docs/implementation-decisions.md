# 当前实现约定与未决事项

依据为 GIB-Chap234-1016.tex 第 2、3、4 章。旧阶段登记与审查历史已归档于源仓库 legacy；当前代码映射见 [论文清单](paper-implementation-map.md)。

| 编号 | 当前约定 |
| --- | --- |
| D01 | 工程内部智能体在前、锚点在后，显式索引；唯一物理边与双向消息分开 |
| D02 | canonical finite binary32 测量表示，按固定支持定义自然对数 log M |
| D03 | 保留论文已知测量方差假设；距离相关已知方差是理想化输入，正式设置需明确说明 |
| D04 | 仅允许 LOS 加性高斯、不截断；其他传播模型及其参数不进入当前生产配置 |
| D05 | 唯一生产场景为四角加中心五锚点、全区域均匀智能体、单一 comm_radius；半径不自动重算 |
| D06 | 通信成本 rho×初值距离²，包含锚点边，不直接称为实测焦耳 |
| D07 | 完整先验与真实已知方差分开；训练预测器下限独立配置，BP 默认无 jitter |
| D08 | 原始 5/4 维输入，消息/更新 MLP 含 LayerNorm，双向传播，无额外外部残差 |
| D09 | 固定 beta/gamma/kappa/eta，温度仅调松弛；正式系数必须显式指定 |
| D10 | 默认确定性 p>0.5，不隐式补边或强制保留锚点边 |
| D11 | 固定先验支持、同步有向 cavity sum-product、概率域可选阻尼；粒子数/轮数正式预算待验收 |
| D12 | 确定性多源 BFS 森林，未锚定分量保留，不虚构连接 |
| D14 | 数据/训练/BP/bootstrap 独立种子，固定数据多种子编排；图与训练种子统计单位分别报告 |
| D15 | NEBP 为完整归档参考，不是已适配的正式对照，不进入发布包 |
| D16 | 当前唯一入口 gib4cl；全部旧入口/旧实现归 legacy；发布包按白名单生成并逐文件校验 |
| D17 | 用户输入仅保留一套结构，删除旧格式转换和固定算法版本；保留图、数据集、完整检查点的读取格式校验与指标协议，删除无读取校验用途的运行/结果版本标签；记录完整参数与源码摘要，模型权重只保存参数张量 |

严格 CPU 验收入口为 python -m tools.accept_cpu；三份核心算法与固定校验数据匹配，并执行独立数学、恢复、指标和面板重放检查。源码包可不带任何 legacy 文件完成这些检查。

仍需完成的正式准入条件：独立依赖安装/锁定、服务器 GPU 数值/资源验收、目标规模预算及验证集预实验，随后冻结正式系数、种子数量与最终评价方案。smoke 完成不代表模型性能已达标。
