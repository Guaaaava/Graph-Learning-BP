## 4. 现有代码职责与调用关系

| 文件或目录 | 当前职责 | 后续处理定位 |
| --- | --- | --- |
| `BP/__init__.py` | 导出 `ParticleBP` | 保留公共推断接口的作用 |
| `BP/particle_bp.py` | 静态二维粒子推断、批图包装 | 按标准排除回传边的 BP 更新修正 |
| `GNN_learning/config.py` | 数据、模型、训练和 BP 的全局常量 | 后续拆为显式实验配置 |
| `GNN_learning/generate_network.py` | 场景、候选边、初值、测量和残差生成 | 统一模型约定及场景元数据 |
| `GNN_learning/generate_datasets.py` | 批量生成并保存训练、验证、测试集 | 明确样本身份、种子、版本和输出隔离 |
| `GNN_learning/dataset.py` | 原始字典转 PyG，锚点局部索引转全局索引 | 建立单一数据契约 |
| `GNN_learning/model.py` | 消息传递、边评分、STE 采样 | 修正双向传播、无向评分和噪声分布 |
| `GNN_learning/loss.py` | 旧版 FIM 任务损失、距离 Bernoulli KL、度数项、CRLB 辅助值 | 按新版预测分布及压缩目标重建 |
| `GNN_learning/train.py` | 主训练、验证及权重保存 | 统一可复现实验入口 |
| `GNN_learning/evaluate.py` | 三类拓扑、另一套 BFS、BP、指标及报告 | 合并基线接口并修正评估和保存 |
| `GNN_learning/exp_50agent.py` | 参数搜索、小规模训练、大规模“微调”和评估 | 旧流程留档；修正模型传递与选择规则 |
| `GNN_learning/exp_anneal.py` | 压缩权重退火、规模微调和评估 | 旧流程留档；避免导入副作用和错误模型评估 |
| `GNN_learning/visualize_topology.py` | 从原始字典画三种拓扑 | 适配统一数据格式并准确命名 |
| `NBP_ST/BFS_tree.py` | 使用原始局部锚点索引构造多源 BFS | 与评估中的 BFS 合并；准确称为森林 |
| `NEBP/train.py`、`NEBP/test.py` | 原参考项目动态跟踪的训练和测试 | 参考材料；当前不属于主方法执行链 |
| `NEBP/utils/synthetic.py`、`prepare_data.py` | 四维位置/速度状态、时序数据及 DGL 图 | 不直接套用于当前静态二维模型 |
| `NEBP/utils/cooperative_localization.py` | 原粒子及神经增强推断器 | 参考来源，不能替代论文公式验证 |
| `NEBP/utils/bp_test.py`、`hybrid_test.py` | 原动态 BP/神经增强方法评估 | 与当前正式验证区分 |
| `NEBP/utils/sqrtm.py` | 矩阵平方根辅助函数 | 保留参考关系 |
