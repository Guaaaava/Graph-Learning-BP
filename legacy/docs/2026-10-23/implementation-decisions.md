# 实现约定与待确定事项

依据：基线 `2026-10-22-step-01`，配套[公式与实现清单](paper-implementation-map.md)。

本文区分“论文已规定”“工程建议”和“待确定细节”。第 2、3 节保留第一步的初始登记；当前状态见第 4 节及各轮落实情况。数据、算法和指标的历史验证说明继续保留；当前目录、独立种子、编排和严格验收入口见 [delivery-and-seeds.md](delivery-and-seeds.md)。工程默认值不代表正式实验参数已确定。

## 1. 论文已规定的边界

1. 静态二维定位；锚点精确已知，未知坐标向量仅含智能体。
2. 每条无向物理测量边一个 `A=(z,v)`、一个概率和一个选边决定。GNN 消息沿两个方向传播。
3. `C` 包含初始坐标、协方差、锚点信息和候选边；选边后仍可用。不能要求候选图与真值统计独立，关键是候选边属于推理时已知网络信息。
4. 模型与预测分布只使用可用输入；真值在训练中用于评价任务损失，也可供独立评估和诊断使用。
5. 测量标准差按 `sigma0+alpha*d` 生成，论文假设其数值已知；局部预测模型使用固定的已知方差及显式下限。
6. 局部高斯预测器在初始位置线性化，以节点先验协方差的逆构造 `J0`，计算预测均值和完整联合精度。
7. 任务项为含误差二次项的高斯 NLL；压缩项为负熵、期望通信代价、期望智能体三角形及测量保留成本。
8. 仅三个顶点全为智能体的三角形计入循环代价。锚点边仍参与通信代价和智能体度数。
9. 任务和度数项使用带 STE 的二值选边；压缩项直接使用概率。每图内部按公式求和，再对输入图平均。
10. `gamma,kappa` 在优化中固定；配分函数对 GNN 参数为常数，可从训练目标移除。`sum(p*log M)` 不能随之移除。
11. 标准 BP 发送消息时排除接收边的反向消息。树上精确性假设精确消息和积分，不自动适用于有限粒子代码。
12. 最终定位由所选子图上的 BP 完成。三角形减少、度数惩罚或代理 NLL 下降均不单独保证 BP 校准、连通性或几何可定位性。

## 3. 符号与现有字段

| 论文量 | 现有来源 | 后续语义要求 |
| --- | --- | --- |
| `Y` | `data.y` / `true_agents_pos` | 位置标签；模型前向与预测分布构造不可读取 |
| `Ybar`、初始节点坐标 | `data.x[:,:2]` / `init_agents_pos`、`anchors_pos` | 由锚点标志区分；锚点没有待估增量 |
| `Sigma0_i` | `data.x[:,2:4]` / 当前标量 `init_agents_cov` | 当前为对角形式；数据契约明确支持范围及正定性 |
| `J0` | 旧 `FIM_PRIOR` 没有直接等价关系 | 从节点先验协方差计算；不能只更名 |
| `z_ij`、`v_ij` | `data.edge_attr[:,0:2]` | 统一有限数值表示及方差单位 |
| 特征 `abs(r_ij)` | `edge_attr[:,2]` | 保持绝对残差；与带符号残差分开 |
| 局部模型 `r_ij` | 当前未单独构造 | 从 `z-dbar` 得到；在 `b_s` 中保留符号 |
| 无向物理边 | 当前 `edge_index` 一边一次 | 未来区分唯一测量边与双向消息边 |
| `p_ij`、`s_ij` | `sigmoid(logits)`、`edge_weights` | 概率与 STE 决定分开；所有成本按物理边计算 |
| `beta` | 旧 `LAMBDA_REG/lambda_reg` 仅角色近似 | 新损失尺度改变，值和调度需重新确定 |
| `gamma` | 旧 `GAMMA` 使用真距离先验 | 改为结构通信成本系数，不能认为原含义完全相同 |
| `kappa`、`rho`、`log M_ij` | 当前缺少 | 显式新增并记录单位/表示约定 |
| `eta` | `ETA/eta` | 新版为每图度数惩罚求和，旧参数不自动保持有效强度 |
| `mu,S` | 当前训练未实现 | 局部高斯预测分布，不等于 BP 最终均值与协方差 |
